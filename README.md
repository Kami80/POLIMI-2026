# Polimi Students 2026/2027

A static, GitHub Pages-ready student directory powered by a Google Sheet.

## Features
- Mobile-first student cards
- Multi-select filters for Program, Gender, Campus and Roommate preference
- Search
- Clickable Telegram profiles
- About/self-description field
- Card/table view on desktop
- Email and Timestamp hidden from the public interface
- Light/dark mode
- Google Form button for adding a profile
- No statistics section

## Deploy on GitHub Pages
1. Upload `index.html`, `styles.css` and `app.js` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save.

The source Google Sheet needs to remain viewable by people who should be able to access the directory data.
